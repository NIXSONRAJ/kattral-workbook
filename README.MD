## 🌟 The Mission (Star of Success Initiative)

This workbook was designed and developed for a 3-day educational program serving **250 students in Chennai, India**. 

The goal of "KATTRAL" (Tamil for *Learning*) goes beyond standard academics. It seamlessly integrates the 3rd Standard English syllabus with core life values. Through 15+ interactive activities, students learn:
* **Humanity & Sharing** (Math & Empathy)
* **Discipline & Routine** (Verbs & Daily Habits)
* **Health & Hygiene** (Nouns & Self-Grooming)
* **Basic Manners** (Vocabulary & "Magic Words")

## 🚀 Technical Highlights

This project was built from the ground up to be a lightweight, zero-dependency, print-perfect web application.

* **Strict A4 CSS Architecture:** Utilized advanced CSS Flexbox, Grid, and `@media print` queries to ensure all 28 pages scale and print perfectly to physical A4 paper without any overlapping or margin bleeding.
* **Zero-Dependency UI:** Designed entirely using scalable CSS styling, native web fonts, and HTML emojis. No heavy external image assets were used, resulting in lightning-fast load times.
* **Document Export Logic:** Implemented Vanilla JavaScript Blob handling to allow educators to export the DOM structure directly into a downloadable `.doc` file.
* **Responsive Puzzle Logic:** Built pure CSS-grid-based logic puzzles (Emoji Mazes and Connect-the-Dots) that maintain their structural integrity across different screen sizes and print formats.
